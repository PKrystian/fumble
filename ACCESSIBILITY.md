# Accessibility

Fumble aims to follow WCAG 2.2 Level AA where practical. The interface is designed for
keyboard navigation, screen readers, browser zoom, touch input, and responsive layouts.

Complex character sheets, third-party book content, maps, imported images, PDFs, YouTube
media, and user-provided wiki content may not always have complete text alternatives or an
ideal reading order.

Report an accessibility barrier through the repository issue tracker or contact Krystian
Pińczak through https://github.com/PKrystian. Include the affected page, browser,
assistive technology, expected result, and a description of the barrier. Do not include
sensitive personal information in a public issue.
