## Session journal

The journal keeps notes, editable transcript fragments, and a summary in separate views.
Session search covers private content locally and is not written to URLs. Campaign,
date, and session number are editable; lists support campaign filters, sorting, and
pagination. Existing sessions migrate without losing notes or language preferences.

Campaign context collections are named, reusable text boards. Sessions can attach
multiple boards and append facts directly. Editing a board updates every linked session.
Exports preview the selected scope and include context by default, with an explicit
option to omit it. Copying with an AI prompt does not contact an AI service.
