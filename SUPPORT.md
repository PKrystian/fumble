# Support

Fumble is a free community project without guaranteed response times or service levels.

## Public questions and bugs

Use the issue templates at https://github.com/PKrystian/Fumble/issues. Search existing
issues first. Do not include character exports, campaign secrets, personal data,
credentials, or copyrighted source files.

## Owner and contact

Fumble and the public instance at https://fumble.krystianpinczak.com are maintained by
Krystian Pińczak. Current professional and email contact channels are available at
https://github.com/PKrystian.

## Security

Do not report vulnerabilities in a public issue. Follow `SECURITY.md` and use GitHub
private vulnerability reporting.

## Content and removal requests

Use the content-report issue template when the request contains no confidential
information. Rights holders may contact the maintainer through the owner profile. Include
the affected URL or file, the basis of the request, and a safe follow-up channel. A
substantiated request may result in the affected data source being disabled or removed.
